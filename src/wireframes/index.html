Wireframes

Phone wireframes

Grayscale frames on the design system's geometry (390 × 844, safe areas, bars, rows, targets): structure and flow, never colour. A frame is a layout and copy reference; the product spec governs behaviour.

How to read it

  • One canvas per package (tabs above); one group per journey; a note under each phone gives the frame's ID (its slug, which tickets cite) and the variations that share its layout.
  • Links go to screens (solid hotspots); in-place changes are toggles (dotted). # = not designed.
  • Every frame is built from the shared parts: the Kit tab.
