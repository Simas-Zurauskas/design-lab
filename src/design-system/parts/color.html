02 Colour

Colour has a job, not a hue.

Tokens are named for what they do (primary, ink, line), never for how they look, so a re-skin changes values in theme.css and nothing downstream.

Roles

The value is theme.css's; the job is written here.

  • Aaprimary

    The main action, what's selected, the brand moment.

  • Aaprimary-strong

    Primary pressed, or on a primary-tinted ground.

  • Aaaccent

    A second voice, used sparingly.

  • Aasurface

    The app's background.

  • Aasurface-raised

    Cards, sheets, fields.

  • Aaline

    Dividers and outlines; decorative, never the only cue.

  • Aaink

    Text and icons.

  • Aaink-muted

    Secondary text, captions, metadata.

  • Aapositive

    Saved, done, success — with words or an icon.

  • Aadanger

    Destructive and error — always with words and an icon.

Pairs that carry text

Every pair text sits on must pass: 4.5 : 1 for body text, 3 : 1 for large text and UI edges. Measure after every change to theme.css.
